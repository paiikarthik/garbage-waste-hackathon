Algorithmic Design

AI Vision & Spatial Intelligence Engine

Pillow CV & Spatial Math

visibility Computer Vision Feature Extraction

Uploaded images are resized to 150x150 RGB matrices. Mathematical statistical extractors derive:

Brightness = (R + G + B) / 3

Color_Variance = |R-G| + |G-B| + |R-B|

Texture_Variance = (std_R + std_G + std_B) / 3

Rules classify into Plastic, Food, E-Waste, Medical, Construction, Sewage with calculated confidence % and user override flexibility.

analytics Neighborhood Cleanliness Index Algorithm

Real-time geospatial health score calculated from open reports weighted by severity:

Penalty = (12 * High/Crit) + (6 * Med) + (3 * Low)

Score = Max(15, Min(99, (100 - Penalty) + 10 * ResolutionRatio))

Grade = A+ (≥90) | B (≥75) | C (≥60) | D (<60)

Green Route Optimizer: Evaluates active hotspot clusters and routes walking/cycling paths through clear parkways.

EcoBot NLP: Pattern-matching conversational engine for recycling & compost guides.
Logistics Optimizer: Spatial volunteer headcount calculator ($Area / 35m^2$).
Impact Multiplier: Carbon footprint estimator ($2.5 \times CO_2$ kg saved per kg plastic).

user_id, points, reason, is_read, type, link, created_at

key Relational Integrity & Indexes

Enforces SQLite PRAGMA foreign_keys = ON; with cascading constraints. Indexes created on tracking_id, user_id, and geospatial coordinates for high-concurrency read operations.

Security Posture

Authentication, Authorization & Hardening

Defense in Depth
lock Stateless JWT Token Auth

HS256 signed JSON Web Tokens expire in 7 days. Payloads encapsulate user_id, role, and username. Verified via FastAPI dependency injection:

Depends(get_current_user)
Depends(get_admin_user)
admin_panel_settings Role-Based Access Control

Strict segregation between Citizen Users and Administrators:

  • • Users can only edit/delete their own posts and organized events.
  • • Admins can moderate statuses, inspect stats, and block abusive users.
security HTTP Security Headers

Injected at ASGI middleware layer across all incoming web responses:

X-Content-Type-Options: nosniff

X-Frame-Options: SAMEORIGIN

X-XSS-Protection: 1; mode=block

Referrer-Policy: strict-origin

Upload Sanitization: Strict extension whitelisting (.jpg, .jpeg, .png, .webp), 10 MB payload ceiling, and UUID4 path decoupling preventing path traversal vulnerabilities.
Evolution & Growth

Production Scalability & Cloud Roadmap

10,000+ Concurrent QPS Target
Phase 1: Database Migration

Transition from SQLite to AWS Aurora PostgreSQL with PostGIS extension for sub-millisecond spatial bounding box queries and polygon geofencing.

Phase 2: Object Storage & CDN

Decouple local file storage to Amazon S3 / Cloudflare R2 with Cloudflare global CDN edge caching for waste report images and certificates.

Phase 3: Async Queue & Caching

Introduce Redis cluster for caching leaderboard queries and Celery / RabbitMQ workers for asynchronous image classification and email alerts.
